# 初稿验证 · 2026-09-05

验证对象仅为三个 HTML 交互初稿，浏览器为 Chrome 152.0.7977.82，由 Playwright 驱动本地独立配置运行。

## 渲染

- 三份单文件直接从 file:// 打开，图片均内嵌，没有外部脚本、字体或图片依赖。
- 首页检查 1280×800、960×720、1280×720、800×500、640×480，未出现图片加载失败；横向书架超出可视区域的封面可通过焦点导航滚入。
- 四个页面均检查 640×480 与 800×500，所测试焦点目标位于可视区域内。
- 本轮已修正低高度首页遮挡、紧凑字号、返回文案以及设置与网格的方向导航。
- 浏览器检查中三个初稿的 pageerror 均为 0。对比页的方向切换与画布选择可用。

## 实际操作检查

- 游戏库选择 Neon Rally → 详情正确显示所选游戏。
- Y 切换收藏 → 详情状态改变 → 返回游戏库后该游戏出现在收藏筛选。
- Enter 触发开始游戏 → 显示尚未配置模拟器 → 焦点进入弹窗 → Tab 保持在弹窗 → Escape 关闭并恢复启动按钮焦点。
- 再按 Escape → 回到原游戏库和 game-2 焦点。
- 标题排序改变游戏顺序。B 的搜索可以把列表过滤为 Neon Rally。
- 降低动态效果可切换；空库可进入添加 ROM 文件夹说明，明确没有设备目录访问能力。
- 每份初稿刷新回首页，收藏等原型偏好仍可保留。
- 游戏库连续 12 次方向键移动的检查中，没有焦点落到不可见区域。网格行列边界、设置两栏、C 列表到预览的关键路径采用明确关系；评审工具不参与方向键选取。

## 验证边界

这里只验证浏览器键盘与点击交互，不等于实体手柄、摇杆、Android 焦点系统或 KONKR 真机通过。没有真实扫描、模拟器启动、SD 卡、性能测量或进程重建验收。Android app 源码与 Gradle 配置未修改，因此本轮没有运行原生构建或单元测试；也没有提交或推送。

本记录覆盖最初三份 HTML 原型。后续已选择 C 并落实到 Compose，见 [方向确认](direction-approved.md) 和 [原生验证](native-verification.md)。
